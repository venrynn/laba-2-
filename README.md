# Условие: 

	Стоимость погонного метра красного шелка стоит Х золотых. Сколько заплатил Грей за
	ткань для своей бригантины если общая площадь парусов на ней S м2, а ширина ткани
	рулоне L см.

# Алгоритм:
1. Начало

2. Известные данные
	- `x`=67 золотых (Стоимость метра)
	- `S`=1500 м2 (Площадь парусов)
	- `L`=42 см (Ширина ткани)

4. Вычисления
   
	Длина ткани равна: `dlina` = `S` / (`L`/100)
	
	1500 / (42 / 100) = 3571,43 м
	
	Стоимость за всю ткань равна: `stoimost` = `dlina` * `x`

	3571,43 * 67 = 239285,7 золотых

6. Вывод ответа
	
	Ответ: 239285,7 золотых

7. Конец

# Реализация

```
#include <stdio.h>
#include <locale.h>
main()
{
	setlocale(LC_ALL, "RUS");
	int x = 67; //стоимость метра
	int S = 1500; //площадь парусов
	int L = 42; //ширина твани```

	
	//расчет длины ткани
	float dlina = S / (L / 100.);

	//расчет стоимости ткани
	float stoimost = dlina * x;

	//форматирование вывода
	printf("Выпишем известные данные \n\nСтоимость метра: %d золотых\nПлощадь парусов: %d м2\nШирина ткани: %d см\n\n", x, S, L);
	printf("Длина ткани равна: %d / (%d / 100) = %.2f\n\n", S, L,dlina);
	printf("Стоимость за всю ткань равна: %.2f * %d = %.1f\n\n", dlina, x, stoimost);
	printf("Ответ: %.1f золотых\n", stoimost);

	return 0;
}
```
